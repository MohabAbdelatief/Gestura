# Gestura – 15s vertical ad

`Gestura-ad-15s-1080x1920.mp4` — 1080×1920 (9:16), 30 fps, H.264, 15.0 s, AAC stereo audio normalized to -14 LUFS.
The soundtrack is an original synth track generated by `audio.py` (no licensing concerns); the spot also reads fine muted.

## Editing / re-rendering
- `ad.html` is the source. Open it in a browser to preview the loop; all timing lives in the
  `tl(...)` calls at the bottom of the file (times in seconds on a 15 s timeline).
- `sym-*.png` are the app's SF Symbols (`hand.raised.fill`, `hand.point.right.fill`, `hand.thumbsup.fill`) rendered
  via AppKit in the accent color; the on-screen icon switches to match each recognized gesture.
- `render.py` drives Brave (or any Chromium) headlessly over the DevTools protocol, seeks the
  animation frame by frame, and encodes with ffmpeg:

```bash
python3 -m pip install --target ./pylib websocket-client
python3 render.py            # full render → silent Gestura-ad-15s-1080x1920.mp4
python3 audio.py             # → soundtrack.wav
ffmpeg -i Gestura-ad-15s-1080x1920.mp4 -i soundtrack.wav -map 0:v -map 1:a -c:v copy \
  -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k -shortest out.mp4
python3 render.py 2.4 7.4    # only review frames at those timestamps → review/
```
